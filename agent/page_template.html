    How the agent works

    A Python pipeline. Each stage writes its own file, so every answer can be traced back through the run.

    1. Search

      Composio's SDK runs targeted queries per app: auth, access and pricing, MCP.

    2. Read

      Fetches the vendor's own pages first and ranks official docs above everything else.

    3. Extract

      An LLM fills a strict schema with one evidence link per field.

    4. Verify

      Seven automatic checks per row. Failures are re-researched on the vendor's domain by a second model.

    5. Audit and score

      Risky claims are corrected with sources, then accuracy is measured on a sample.

        Run it yourself

        Code, README and every intermediate file are in . The results are also published as results.json and results.csv for other agents to read.

        pip install -r requirements.txt
cp .env.example .env               # Composio + Groq keys (Gemini optional)
python -m agent.research           # pass 1: research all 100 apps
python -m agent.verify             # pass 2: checks, then re-research failures
python -m agent.score --make-sample
python -m agent.score --final      # merge the sourced audit
python -m agent.score              # accuracy: pass 1, pass 2, final
python -m agent.build_page         # this page
