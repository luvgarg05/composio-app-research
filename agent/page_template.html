        Run it yourself

        Source, README and raw outputs: 

        pip install -r requirements.txt          # composio, openai-compatible client, requests, bs4
cp .env.example .env                      # COMPOSIO_API_KEY, GEMINI_API_KEY and/or GROQ_API_KEY
python -m agent.research                  # pass 1: research all 100 apps (resumable, parallel)
python -m agent.verify                    # pass 2: checks + re-research of failures
python -m agent.score --make-sample       # check sheet (20 apps, 2 per category)
python -m agent.score --final             # final = pass 2 + audited corrections
python -m agent.score                     # accuracy: pass 1 vs pass 2 vs final
python -m agent.build_page                # this page

        Machine-readable outputs for other agents: results.json · results.csv. Each row carries the evidence URL behind every field.
